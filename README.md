# 🖌️ Calculadora de Tinta para Paredes

Um programa simples em Python que calcula a quantidade de tinta necessária
para pintar uma parede com base nas suas dimensões.

## 📋 Sobre o Projeto

Este foi um dos meus primeiros projetos em Python, desenvolvido para praticar
conceitos básicos de programação como entrada de dados, operações matemáticas,
formatação de strings e estruturas de repetição.

## ⚙️ Funcionalidades

- Calcula a área total da parede (largura × altura)
- Estima a quantidade de tinta em litros necessária para a pintura
- Permite calcular múltiplas paredes em sequência

## 🚀 Como Usar

1. Certifique-se de ter o Python instalado na sua máquina
```
```
2. Execute o programa:
```bash
   python Calculadora-tinta-parede.py
```
4. Informe a largura e a altura da parede quando solicitado
5. Veja o resultado e decida se deseja calcular outra parede

## 🧮 Lógica de Cálculo

- **Área:** `largura × altura`
- **Tinta:** `área ÷ 2` (considera o rendimento médio de 2m² por litro)
